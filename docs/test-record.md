# MaixCAM 复测记录

## 性能与稳定性

| 测试项 | 测试方法 | 结果 |
| --- | --- | --- |
| 视觉推理流水线平均耗时 | `dual_buff=True`，仅计连续 `detect()`，300 次 | 25.094 ms |
| 视觉推理流水线中位耗时 | 同一轮 300 次测量 | 25.366 ms |
| 视觉推理流水线等效 FPS | 由平均耗时换算 | 39.85 FPS |
| 视觉推理流水线 P95 耗时 | 同一轮 300 次测量 | 25.771 ms |
| 视觉推理流水线最小 / 最大耗时 | 同一轮 300 次测量 | 23.393 / 29.208 ms |
| 完整运行平均 FPS | `dual_buff=True`，18 个 10 秒窗口 | 29.98 FPS |
| 完整运行窗口范围 | 同一轮 18 个窗口 | 29.95–30.02 FPS |
| 同步单帧对照耗时 | `dual_buff=False`，仅计 `detect()` | 41.704 ms，补充对照 |
| 连续运行 | 连续运行 10 分钟 | 待实测 |

FPS 采样方式：双缓冲流水线 300 次；完整运行预热 30 秒后统计 180 秒、18 个 10 秒窗口。结果由测试应用在终端和屏幕最终结果页输出，不写入设备文件。
